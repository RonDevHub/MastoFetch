# CHANGELOG

## Anpassungen
- Das Design der Index und der Widget Seiten wurden angepasst
- Die Grids wurden überarbeitet und passen sich nun dynamisch der Breite des Widgets an
- Themes wurden hinzugefügt und können nun in der `config/accounts.json` definiert werden
- Über die Variable `DISABLE_DOCS` kann nun die index.php aktiviert oder deaktiviert werden
- Funktion wurde hinzugefügt mit der man auch mehrere API's von einer Instanz definieren kann (wenn man z.B. auf einer Instanz mehrere Accounts hat)
- Caching wurde angepasst, so kann nun für jedes Widget eine eigene Zeit definiert werden
- OG-Vorschaubilder werden nun gecacht und über diese angezeigt
- Neue Toots werden automatisch nachgeladen und angezeigt ohne das Widget neu geladen werden muss
